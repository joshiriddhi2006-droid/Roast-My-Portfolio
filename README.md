# Roast My Portfolio 🔥

An AI-powered web app that reviews portfolio websites and gives feedback on UI/UX, performance, accessibility, strengths, and areas for improvement.

## Live Demo

https://roast-my-portfolio.onrender.com/

## Features

- Portfolio URL submission
- AI-powered portfolio review using Gemini
- Overall score
- UI/UX score
- Performance score
- Accessibility score
- Strengths and improvement suggestions
- Score overview chart
- Responsive design
- Dark/light mode

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Gemini API

## Run Locally

1. Install dependencies:

```bash
npm install
```
